# Maintenance

Owner and contributor working documents live here, outside Docusaurus's published
`docs/` tree. Public source-status records remain in `docs/appendix/` and
`docs/hobby/`; public image provenance and usage terms remain in `docs/shared/`.

| Directory | Contents |
| --- | --- |
| [content/](content/) | Editorial plans, photo sourcing backlog, and diagram backlog |
| [audits/](audits/) | Dated audit snapshots; historical observations may no longer describe the current site |
| [runbooks/](runbooks/) | Owner procedures for external services and site operations |

Start with the [Search Console runbook](runbooks/search-console.md) for console setup,
the [photo backlog](content/photo-backlog.md) for photography work, or the
[content plan](content/content-plan-lifecycle-qualification-low-level.md) for
remaining evidence and example work. See [Contributing](../.github/CONTRIBUTING.md)
for local commands and CI gates.
