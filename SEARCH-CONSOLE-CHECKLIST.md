# Search Console checklist — Connector Field Guides

Owner runbook for Google Search Console (GSC) and Bing Webmaster Tools (BWT).
**Nothing here has been done automatically** — every step needs the owner, signed
in to each console, with authorization for the property.

Property: `https://zcohen-nerd.github.io/connector-engineering-field-guide/`
(a URL-prefix property — the site is a GitHub Pages *project* subpath, so a
Domain property is not possible; the apex `zcohen-nerd.github.io` is not owned).

## 1. Verify the property

1. GSC → *Add property* → **URL prefix** →
   `https://zcohen-nerd.github.io/connector-engineering-field-guide/`.
2. Choose the **HTML tag** method. Copy the `content` token.
3. In `docusaurus.config.ts`, uncomment the `google-site-verification` line in
   `headTags` and paste the token:
   ```ts
   {tagName: 'meta', attributes: {name: 'google-site-verification', content: '<token>'}},
   ```
4. `npm run build`, deploy, then click **Verify** in GSC.
5. Repeat for **Bing** (`msvalidate.01`) — or use BWT's "Import from GSC".

> The `<meta>` route matters: because this is a subpath property, the token must
> render on `…/connector-engineering-field-guide/` (it does — `headTags` are
> global).

## 2. Submit the sitemap

- GSC → *Sitemaps* → submit
  `https://zcohen-nerd.github.io/connector-engineering-field-guide/sitemap.xml`
- BWT → *Sitemaps* → same URL.
- The sitemap is generated by `@docusaurus/plugin-sitemap` on every build (89
  docs + `/`). No `lastmod` is emitted — expected; not an error.

> Host-root `robots.txt` caveat: crawlers read
> `https://zcohen-nerd.github.io/robots.txt`, which this repo does not own. The
> `static/robots.txt` here is informational. Submitting the sitemap URL directly
> is the reliable path.

## 5. Monthly review (~15 min)

- GSC *Pages*: any new **"Discovered – currently not indexed"** or
  **"Crawled – not indexed"**? Investigate the specific URLs.
- Any **coverage errors** (server error, redirect error, soft 404)?
- *Performance*: queries that lost > 5 positions; pages with impressions but
  < 1% CTR (title/description candidates).
- Spot-check that `sitemap.xml`, `robots.txt`, `site.webmanifest`, and a sample
  canonical still resolve (run the site build's link check).
- Re-inspect any page edited that month.
