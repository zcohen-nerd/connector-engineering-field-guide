# Image Attributions

This is the paper trail for every externally sourced raster image in `static/img/photos/`. The captions stay next to the photos; this page keeps the source and license details in one place so they're easy to check. **This repository does not relicense any photo.** Each source image keeps its own license terms.

Some older imports didn't record whether the file was resized or had its metadata stripped. Those rows say “not recorded” instead of pretending we know. Newer assets list the exact changes.

## Audit notes

- The ten assets introduced in the 2026-08 passes were verified directly on their Wikimedia file pages. The existing assets have source links and stated reusable licenses preserved from their page captions; their older imports lack a centralized verification log.
- The older imports also lack a recorded transformation history. This does not alter their source attribution, but a future replacement or crop should be verified at the original source and recorded here at the time it is made.
- No manufacturer marketing image was added in this pass. The CIR-series photo remains included only because its Wikimedia source marks it public domain; retain that source record when auditing future reuse.
